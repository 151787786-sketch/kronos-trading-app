# Kronos 股票交易助手（模拟交易 APP）

基于 Kronos 金融 K 线大模型的本地股票分析 + 模拟交易 Web 应用。
真实 A 股行情 + AI 预测 + 技术指标 + 交易信号 + 模拟账户 + 策略回测。

## 启动

双击 **`D:\a\kronos\启动交易APP.bat`**，浏览器打开 **http://localhost:7071**

> 首次打开后建议先点"➕ 添加自选"加入股票（如 600585 海螺水泥），
> 第一次做 Kronos 预测会加载模型，等待 10~30 秒属正常。

## 功能一览

### 📋 盘前速览（新增）
- **一键看全**：外围市场（美股/港股/日韩）+ 赛道热度（自选分组）+ 自选异动 + 荐股 Top5 + 每日要闻，五大板块聚合在一个页面
- 打开"盘前速览"tab 即得当日全景，早上一眼看全

### 🛡️ 风控与可信度（新增）
- **预测置信带**：Kronos 预测曲线叠加误差带（±15% 典型水平），标注模型局限，提醒"预测仅供参考"
- **跟投风控**：一键跟投单票上限为总资产 20%，超限拒绝；跟投成功后自动生成止损/目标计划
- **行情智能缓存**：盘中（9:30-15:00）日线 5 分钟刷新、分钟线 1 分钟刷新；盘后长缓存——盘中数据实时，不再等 12 小时

### ⭐ 自动荐股（全市场排行榜 + 每日要闻）
- **全 A 股扫描**：从全市场涨幅榜（新浪接口，候选池 40+ 支）综合打分（动量/技术/基本面/Kronos预测可选），排出 Top 3/5/8，**不限于自选股**
- **排行榜样式**：排名徽章（前三名高亮）、涨跌幅、量比、换手、PE、综合评分
- **一键加自选**：每张卡片有"➕加入自选"按钮，一键入库
- **详情弹窗**：点击卡片弹出——打分明细、推荐理由、K线图、买卖点、基本面快照
- **📰 每日要闻**：同页下方展示今日 5 条重要财经新闻（标题/媒体/时间，可点原文）
- 10 分钟缓存；"含 Kronos 预测"开关控制等待时间

### 🔥 赛道分组（新增，适配"景气赛道打底"）
- **自选股按赛道分组**：勾选"赛道分组"开关，自选股按 AI/新能源/消费/周期…分组展示
- **赛道热度**：每组显示平均涨幅、上涨/下跌家数、领涨股，按热度自动排序——一眼看出**哪条赛道整体在动**
- **分组管理**：添加自选时选分组；自选股悬停 🏷 图标可随时改分组
- 每只自选股显示所属赛道标签（蓝色小标）

### 🌐 外围市场 + 轮动监控（新增，适配"景气赛道轮动"玩法）
- **外围面板**：顶部实时显示美股三大指数（道指/纳指/标普）、恒指、国企指数、日经225、韩国KOSPI，红绿涨跌，60 秒自动刷新——开盘前看外围、跟节奏
- **自选轮动排序**：自选股可按**涨幅 / 量比 / 换手**排序，谁被资金关注（放量/大涨/涨停）一目了然，直接点击扑击
- **异动标记**：每只自选股自动打标（涨停/大涨/大跌/放量/量增）
- **盘中异动提醒**：后台每 60 秒扫描自选股，涨幅≥3% 或量比≥2.5 触发**大幅拉升/放量异动**提醒，可推送到微信

### 💰 模拟交易（多账户 + 自动接管 + 一键跟投）
- **多模拟账户**：可创建多个独立账户（短线/长线/测试），各自资金/持仓/委托完全隔离，顶部下拉切换
- **模拟交易**：买入/卖出（A股规则：买入整手、佣金万三最低5元、卖出印花税万五）
- **快速下单**：交易页可直接输入代码/名称下单，无需先选自选；持仓点击可快速卖出
- **⚡ 一键跟投**：自选里**表现好的股票**（涨幅>0 或量比>1）旁显示跟投按钮，一键按现价买入（默认账户可用资金 10%，可指定金额），自动解析名称、整手取整
- **🔔 买卖点提前预警**：现价接近买入区间/止损/目标价（1.5% 内）提前提示（"距买点仅 X%"），买卖点页实时显示 + 后台监控记录事件 + 可推送微信
- **🤖 自动接管**：绑定账户 + 设置规则（涨幅/跌幅/量比阈值、量价信号），后台每 60 秒检查，触发自动买入/卖出，含规则开关、执行日志（可推送微信配合）

### 📋 基本面分析（新增）
- **公司概况**：名称/行业/地区/员工数、主营业务简介
- **估值快照**：现价、总市值、流通市值、**PE(TTM)/PB/EPS/每股净资产**、换手率
- **财务摘要**：最近 4 个季度营收/净利及同比、ROE、毛利率、净利率、EPS
- **判断汇总**：自动生成定性判断（增长/放缓、估值水平、市值档次）
- **公司公告**：精确匹配该股票的近期公告（消息面参考，可点开详情）
- 数据源：腾讯行情（估值）+ 东财数据中心（财务/公告），自动绕代理

### 🖥️ 系统状态（新增）
- 顶部实时显示：模型加载状态、计算设备（GPU 型号/CUDA 版本）、行情缓存文件数/大小

### 📊 行情与图表
- **自选股列表**：实时价格/涨跌幅，30 秒自动刷新；**悬停显示 ✕ 可删除**；点击进入分析
- **多周期 K 线**：日线 / 60/30/15/5/1 分钟线，任意切换，**切换周期时相关面板自动跟随刷新**
- **K 线 + 指标**：蜡烛图叠加 MA5/10/20/60、BOLL、MACD、RSI、KDJ（右上角切换）
- **Kronos 预测**：紫色曲线为 AI 对未来 30/60/120 根的预测（含上/下轨），基于最近 400 根 K 线

### 🎯 买卖点（新增）
- 一键给出**操作建议**：买入 / 卖出 / 持有 / 观望（综合得分制）
- **买入区间 / 目标价 / 止损价**：基于 ATR 波动率和 Kronos 预测高低点
- **关键价位**：自动识别支撑位、压力位（摆动点聚类）、布林带、MA20/MA60
- 每一条操作依据都列明：均线排列、MACD、RSI、KDJ、Kronos 预测方向

### 📐 预测准确率（新增）
- 滚动样本外验证：用历史 K 线"预测过去"，和真实走势对比
- 输出：MAE / RMSE / MAPE / **方向准确率**、逐轮明细图
- 让你知道模型在哪些情况下靠谱、哪些时候别信

### 📊 多股对比（新增）
- 2~N 只股票归一化收益曲线叠加对比（起始 0%）
- 表格列出区间涨幅，一眼看出谁强谁弱

### 🤖 多股预测对比（新增）
- 对多只股票分别跑 Kronos 预测
- **预测涨跌幅柱状图**（红绿对比）+ **归一化预测走势曲线叠加**
- 表格列出每只的当前价/预测终点/预测涨跌

### 🔔 提醒中心（新增）
- **买卖点计划管理**：一键为全部自选股生成买入区间/目标价/止损计划
- **自动触发监控**：后台每 60 秒检查现价，触发三类提醒：
  - 📥 进入买入区间（可分批建仓）
  - 🛑 触及止损价（建议减仓）
  - 🎯 达到目标价（建议止盈）
- **触发历史**：所有触发记录（时间/股票/类型/价格/说明）
- **微信通知**：支持 Server酱 / PushPlus 两种免费渠道，触发时自动推送到微信
  - Server酱：https://sct.ftqq.com 微信扫码获取 SendKey
  - PushPlus：https://www.pushplus.plus 扫码获取 token
  - 支持"测试推送"验证配置

### 📄 导出报告（新增）
- 一键导出 CSV 报告：预测明细（日期/开高低收/量）+ 操作建议 + 关键价位

### 💰 模拟交易
- 初始 **100 万** 模拟资金（A 股规则：100 股整手、佣金万三最低 5 元、卖出印花税万五）
- 买入/卖出 → 自动计算手续费、更新持仓成本
- **持仓列表点击任意持仓即可快速跳转卖出**（自动预填价格/数量）
- 持仓面板：现价、市值、浮动盈亏；历史委托全部记录
- "重置账户"一键回到 100 万初始状态

### 📈 策略回测
- 4 种策略：综合信号 / 均线金叉死叉 / MACD 金叉死叉 / RSI 超买超卖反转
- 输出：总收益、年化、最大回撤、胜率、交易明细、策略 vs 买入持有对比曲线

## 添加股票

右上角 **➕ 添加自选**，输入 **6 位 A 股代码** 或 **股票名称**（如 `000001`、`600519`、`300750`、
`688836`、"比亚迪"、"宁德时代"），系统自动解析为标准代码。
数据通过腾讯行情接口实时获取并本地缓存 12 小时，点击"刷新行情"强制更新。

## 环境要求

- Windows 10/11，Python 3.12（已内置虚拟环境 `D:\a\kronos\.venv`）
- NVIDIA GPU + CUDA 驱动（可选，无 GPU 自动降级 CPU 运行）
- 磁盘剩余 ≥ 8 GB（模型权重 + 缓存）
- 可访问 `gu.qq.com` / `qt.gtimg.cn` / `smartbox.gtimg.cn`（腾讯行情，国内网络直连）

运行前提：先启动服务（双击 `启动交易APP.bat`），再在 `trading-app` 目录执行测试。

## 常见问题排查

- **端口 7071 被占用**：启动脚本会自动检测，若已在运行则直接打开浏览器。
- **模型加载失败**：检查 `D:\a\kronos\models\` 下存在 `Kronos-base` 和 `Kronos-Tokenizer-base`。
- **提示"未找到 XX 的日线数据"**：代码输入错误或该代码暂无数据，请确认 6 位代码。
- **预测很慢**：首次加载模型 10~30 秒属正常；后续预测 CUDA 约 1-2 秒。
- **行情不更新**：数据缓存 12 小时，点"刷新行情"强制更新。

## 数据与存储

- 行情缓存：`trading-app\data\*.csv`
- 账户/持仓/委托/自选/提醒：`trading-app\trade.db`（SQLite）
- 微信通知配置：`trading-app\notify_config.json`（仅存 token，本机使用）
- Kronos 模型权重：`D:\a\kronos\models\`（Kronos-base + Tokenizer-base，GPU CUDA 自动启用）

## 与官方 webui 的区别

官方 webui（端口 7070，`启动Kronos.bat`）只有"选数据→预测"；
本 APP（端口 7071）是完整交易工作台：行情、指标、信号、模拟交易、回测、提醒、微信通知。
