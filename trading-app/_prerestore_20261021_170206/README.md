# Kronos 股票交易助手（模拟交易 APP）

基于 Kronos 金融 K 线大模型的本地股票分析 + 模拟交易 Web 应用。
真实 A 股行情 + AI 预测 + 技术指标 + 交易信号 + 模拟账户 + 策略回测。

## 启动

双击 **`D:\a\kronos\启动交易APP.bat`**，浏览器打开 **http://localhost:7071**

> 首次打开后建议先点"➕ 添加自选"加入股票（如 600585 海螺水泥），
> 第一次做 Kronos 预测会加载模型，等待 10~30 秒属正常。

## 功能一览

### 🔴 实时盯盘（交易舱 v1 · P0 新增）

独立标签页 `🔴 实时盯盘`，基于腾讯免费行情接口的多周期轮询引擎。

**数据源与时效**
- 接口 `https://qt.gtimg.cn/q=市场前缀+代码`，一次批量拉多只；**gb18030** 解码，`~` 分隔，共 88 字段
- **行情时效唯一依据 = `fields[30]`**（`YYYYMMDDHHMMSS`），**不使用** DSA 的 `update_time`
- 每张卡片显示行情时刻与「距今 N 秒」，超过 60 秒标黄；>5 分钟视为不新鲜、卡片降级为虚线

**多周期轮询**
- 四档预警周期 **1 / 3 / 5 / 10 分钟**，**按自选股逐个配置**（默认 5 分钟）
- 引擎 tick 可配：0.5s / 1s（实验档）/ 5s / 30s（保守档）——tick 只决定「检查时机」，
  每只股票仍按自己的周期到期，1 分钟周期的股不会因 tick 密集而被过度请求
- **掉线自动重连**：连续失败指数退避（1→2→4→8→16→32→60 秒封顶），恢复后计数并回到正常节奏；
  单次失败不会让轮询中断

**买卖点红绿频闪（A 股惯例）**
- **买点 → 绿闪**、**卖点 → 红闪**，0.9 秒呼吸节奏，价格数字同步染色
- 幅度达标 + 放量/换手共振 → 升级为三级「危险级」
- 仅「放量但幅度未达标」→ 关注级，**只记录不频闪**，避免噪声干扰
- 频闪严格按 `symbol` 匹配：只有该标的同时出现在行情列表与事件列表时才闪
- 可用「静音频闪」开关一键关闭所有闪烁；开启系统「减少动态效果」时自动改为静态描边

**限流策略**

| 项 | 默认值 | 说明 |
|---|---|---|
| 单批上限 | 500 只 | 超出自动分批 |
| 请求间隔 | 500 ms | 全局节流，跨线程共享 |
| 行情缓存 | 5 秒 | 同代码 5 秒内不重复打接口 |
| 并发上限 | 3 | 信号量控制 |
| 429 处理 | 指数退避 | 0.5→1→2→4→8 秒，叠加在正常节流之上 |

间隔与 tick 均可在页面上调整（请求节流 500/1000/2000ms，tick 0.5/1/5/30 秒）。

**接口频次探针**
- 三档实测：**30 秒（保守）/ 1 秒（实验）/ 0.5 秒（激进）**，默认只跑保守档
- 每档记录：成功率、均值/中位/P95/最大耗时、**429 次数**、**软限流次数**（返回 200 但字段异常）
- 自动给出建议安全档位，并附免责声明：结论限于**本机、本时段、本次样本量**
- ⚠️ 需求中的「压测一周无封禁」需要长期后台运行，本工具支持但**不在单次运行内完成**

> **实测结果**（2026-10-20 下午，3 只标的）：1 秒档 5 次全部成功，无 429，
> 均值 200ms / P95 390ms；0.5 秒档 3 次全部成功，均值 224ms。
> 这是短样本结果，**不能作为长期压测结论**。

**关于 DSA**
- 需求提到的 DSA 服务（`http://127.0.0.1:8000/api`）本机未运行、接口契约未知，
  故本模块**直接用腾讯接口**，DSA 适配层留空。DSA 启动后可按其真实返回结构接入。

### ⚡ 盘中变化时刻线 + 前置预警线（P0 新增）
- **盘中变化时刻线**：扫描 **1 分钟 K 线**，单根振幅 ≥3% 或量能 ≥2.5 倍均量即在 K 线图上打一条**垂直虚线**（向上绿▲ / 向下红▼）
- **前置预警线**：每个异动时刻**前 10 分钟**（可配置）画一条橙色点线，提前量可调；前置时点早于开盘（09:30）时自动取消并说明原因
- **历史回溯**：一次扫描 400 根 1 分钟 K 线，页面上给出「异动时间轴」，**点击任意 chip 即把图表跳到该时刻**
- **依据卡片**：每条异动附**因子贡献明细**（振幅突破 / 量能突破 / 同向累计，各自 +N 分）、**风险因子**（−N 分）、**回测参考**（同类场景方向延续准确率与平均收益、样本量）
- **参数溯源**：每个阈值标注**来源**（历史回测 / 经验规则 / 自迭代校准 / 数据不可用）与依据说明，鼠标悬停可见完整理由
- 可在面板上用开关随时隐藏/显示时刻线与前置预警线，不重新请求数据

> **数据口径声明**：本模块基于 1 分钟 OHLCV。需求中依赖 Level-2 的因子
> （委托簿撤单率、大单流向、主动买卖比、封单比）在本机数据源下**无法取得**，
> 界面会以红色区块**显式标注「数据不可用」且不计入评分**，不会编造数值。
> 同时自动清洗 15:00 收盘集合竞价 bar（撮合累计量会造成虚假放量）与零成交/一字板 bar。

### 🚨 全屏爆红/爆绿 + 一键静默（P0 新增）
- **全屏视觉冲击**：剧烈异动时全屏泼色 —— 拉升**爆绿**、下杀**爆红**，快速闪烁（2Hz），默认 3 秒后自动消失或条件解除
- **一键静默**（三种方式）：点击屏幕任意位置 / 按 **Esc** / 点 **「🤐 闭嘴」** 按钮
- **声音联动**：Web Audio 合成提示音（无需外部音频文件），可在设置里关闭
- **震动**：移动端走 `navigator.vibrate`（三级急促跟随节奏）
- **桌面通知**：授权后异动时同时弹系统通知（`Notification` API），需点「🔔 开启桌面通知」授权
- **预警悬浮摘要**：右下角常驻卡片记录最近 4 条预警，可单条关闭、30 秒自动消失

### 🛡️ 防干扰机制（P0/P1 新增）
| 机制 | 说明 |
|---|---|
| **冷静期** | 全屏预警关闭后，同方向 N 分钟内不再触发（默认 5 分钟，可调 1~60） |
| **强度阈值** | 滑块调节（30~95 分），分数越高越少打扰，默认 70 分 |
| **免打扰时段** | 设置起止时间后，该时段内屏蔽所有视觉/声音/震动，支持跨零点（如 22:00~09:00） |
| **单一标的锁定** | 填 1~3 只代码则**仅这些标的**触发全感官预警，其余只记录到悬浮摘要 |
| **动效降级** | 系统开启「减少动态效果」（`prefers-reduced-motion`）或 APP 动效关闭时，全屏预警自动改为静态高对比显示，不闪烁 |

设置项保存在浏览器本地（`localStorage`），面板内有 **「▶ 测试全屏预警」** 可随时验证效果。

### 🔬 科学依据中心 · 高级预判 V3.1（P3 新增）

K 线页底部新增「🔬 科学依据中心 · 高级预判」面板，四个标签页：

**📐 参数溯源**
- 全系统 **38 个可调参数**汇总成一张表，分 7 组：盘中异动 / 下探预警 / 尾盘预判 / 异动提醒 / 风控扫描 / 荐股权重 / 投研会
- 每项标注：**生效值 · 默认值 · 来源（历史回测 / 经验规则 / 自迭代校准 / 数据不可用）· 允许范围与步长 · 依据说明**
- 🟡 黄色行 = 已被夜间自迭代改动（可对比默认值）；🔴 红色项 = 数据源不可得已降级
- 参数命名与 tuning 路径一致（如 `anomaly.wave_pct`），界面与配置不会出现两个名字

**🩺 诊断面板**
- 基于**真实运行统计**（异动频次、用户反馈、快照积累、自迭代改动）指出哪个参数可能在拖后腿
- 每条给出「现象 → 原因 → 可执行建议」，例如「『晚了』占比偏高 → 上调 lead_minutes 提前预警」
- 明确声明：样本量小的结论仅供参考，不构成参数调整建议

**🧪 模拟器**
- 拖动滑块调整 `wave_pct` / `vol_ratio` / `cool_down_min` / 持有期，点「运行模拟」
- 用**真实历史 1 分钟 K 线**分别跑一遍调参前后的检测，对比**触发次数**与**方向兑现率**
- 数据不足时**明确拒绝**：「历史 K 线不足，无法模拟 —— 不会给出编造的回测结果」
- 结果全部来自实际计算，样本偏少时会额外警示

**⚡ 高级预判（V3.1）**
- **动量衰减检测**：用价格一/二阶差分识别动能变化，区分四种状态 ——
  横盘（无动量）/ 动量停滞 / 动量衰减 / 拐点反转，并给出人话解释
- **盘口异动监测**：本机数据源不提供 Level-2，**明确声明不可得**并列出所需数据；
  同时提供「放量 + 振幅压缩」的**代理指标**推测挂单堆积，界面显著标注「不是真实盘口数据」
- **ML 异动概率分**：逻辑回归，特征全部来自 1 分钟 OHLCV，输出 0~1 概率
  - 同时展示 **训练准确率 / 样本外准确率 / 基线率**，并计算边际（edge）
  - **样本不足时拒绝训练**，不返回没有统计意义的分数
  - 模型未显著优于基线率时会明确警示「该分数参考价值有限」

### 🗂️ 预警快照 · 时间轴 · 日报 · 反馈闭环（P2 新增）

K 线页底部新增「🗂️ 预警复盘」面板，三个标签页：

**🕐 预警时间轴**
- 当日所有二级及以上预警按时间顺序排列成横向时间轴，圆点带级别配色（二级橙 / 三级红）与方向外圈（绿=向上、红=向下）
- **点击圆点 → K 线图跳到该时刻**，同时弹出该条预警的快照详情
- 已评价的预警在时间轴上显示 👍/👎/⏰ 标记

**🗂️ 预警快照**
- **二级（警告级）及以上预警自动存档**：截存当时的 120 根 1 分钟 K 线 + 关键指标 + 依据卡片
- 点击任意快照查看详情：级别 / 方向 / 强度评分 / 触发价格 / 窗口涨跌与振幅 / 末根量比 / **快照 K 线图** / 因子贡献明细
- 存的是**数据而非图片** —— 可以重新渲染、可以参与统计，比截图更有复盘价值

**📊 每日日报**
- 收盘后自动汇总：快照数、事件总数、**类型分布 / 标的分布 / 方向分布 / 级别分布 / 小时分布**（条形图）
- **走势回溯**：对每条预警检查其后 30 根 K 线内方向是否兑现，给出已验证条数、待验证条数与兑现率
- 数据不足以验证时明确标为「待验证」，**不硬算准确率**

**🗳️ 用户反馈闭环**
- 每条预警可一键评价「👍 有用 / 👎 无用 / ⏰ 晚了」
- 反馈汇总会给出可执行建议，例如「『晚了』占比偏高 → 建议提前前置预警时间」
- 界面明确标注：这是**用户主观评价，不等于模型真实准确率**，与日报的走势回溯分列呈现

### 📉 下探过程实时预警（P1 新增）
- **四阶段拆分**：按当日实时量价自动判定所处阶段，页面用四格步骤条高亮「当前」：

| 状态 | 特征 | 系统行为 |
|---|---|---|
| 正常回撤 | 跌幅 < 1.5%，量能正常 | 不预警 |
| 加速下杀 | N 分钟内连跌且斜率变陡 | 触发关注级 |
| 恐慌释放 | 放量下跌，买盘稀疏 | 触发警告级 |
| 抛压衰竭 | 二次下杀量 < 首次，不再创新低 | 「可能止跌」蓝条提示 |

- **下探质量评分（Dip Quality Score, 0-100）**：实时计算并在页面上用带游标的渐变条展示
  - **≥65 分「洗盘型下探」**：缩量止跌、站于均价线上方、跌势不连续
  - **≤40 分「出货型下探」**：放量恐慌释放、双支撑失守、回撤过深
  - 每个加/减分项都列出**因子名 + 贡献分 + 依据说明**

### 🎯 尾盘走势预判（P1 新增）
- **六因子加权**（权重为需求指定值，可被夜间自迭代覆盖）：

| 因子 | 权重 |
|---|---|
| 午后不再创新低 | 0.25 |
| 股价站回均价线上方 | 0.30 |
| 14:00-14:30 连续主动性买单 | 0.20 |
| 板块内有跟风票 | 0.10 |
| 该股近 20 日深水拉板历史 | 0.08 |
| 大盘环境偏暖 | 0.07 |

- **三种尾盘结论**：**真抢筹**（放量回均价线、板块共振）→「尾盘攻击概率高，可跟踪打板」；
  **假拉升**（无量直拉 / 偏离均价线大 / 日线高位）→「诱多概率高，次日易低开」；**磨尾盘** →「无趋势，观望」
- **14:30 预警线**：站回均价 + 板块强 → 绿条「尾盘转强」；仍在最低价区 + 无量 → 红条「尾盘杀跌延续」
- **依据卡片**：概率 ≥70% 触发，逐条列出六因子的命中情况、权重、贡献分与依据

### 🕛 午间复盘快照（P1 新增）
- 11:30 口径自动汇总：上午最低点、最大跌幅、均价线位置、上午量能占全日比例、板块排名
- **午间三剧本假设**并给出概率排序：午后继续杀 / 水下震荡磨筹码 / 尾盘拉板，每个剧本附触发特征与应对动作

### 🔧 日内自适应校准（P1 新增）
- 开盘 30 分钟后，按**当日已实现波动率 / 基准波动率**自动缩放异动阈值（钳制在 0.5~2.0 倍）
- 高波动日上调（防噪声刷屏）、低波动日下调（防漏报），并说明调整方向与理由
- 量能阈值按缩放系数的**平方根**调整（对波动率敏感度低于价格阈值）
- 基准交易日不足时**明确声明未校准并沿用基准值**，不硬套默认值

> **关于「主动性买单」的诚实说明**：真实主动买盘需要 Level-2 逐笔成交方向标记，
> 本机数据源不提供。该因子以「14:00-14:30 上涨分钟占比 + 量能相对放大」作为
> **代理指标**计算，界面用橙色「代理」徽章明确标注，绝不冒称是真实逐笔买盘。
> 封单比、撤单率等因子同样标注为「数据不可得」且不计入分母。

## 常见问题排查

- **端口 7071 被占用**：启动脚本会自动检测，若已在运行则直接打开浏览器。
- **模型加载失败**：检查 `D:\a\kronos\models\` 下存在 `Kronos-base` 和 `Kronos-Tokenizer-base`。
- **提示"未找到 XX 的日线数据"**：代码输入错误或该代码暂无数据，请确认 6 位代码。
- **预测很慢**：首次加载模型 10~30 秒属正常；后续预测 CUDA 约 1-2 秒。
- **行情不更新**：数据缓存 12 小时，点"刷新行情"强制更新。

## 数据与存储

- 行情缓存：`trading-app\data\*.csv`
- 账户/持仓/委托/自选/提醒：`trading-app\trade.db`（SQLite）

## 与官方 webui 的区别

官方 webui（端口 7070，`启动Kronos.bat`）只有"选数据→预测"；
本 APP（端口 7071）是完整交易工作台：行情、指标、信号、模拟交易、回测、提醒、微信通知。
