## 一、需求整理（结构化）

### 1. 业务目标
构建**多 Agent 投研数字员工团队**，通过「圆桌辩论 + 交叉互评」抑制 AI 幻觉，产出：标的分析、估值、风险评估、调仓方案；并与现有 Kronos 预测结果做**交叉验证**。

### 2. 角色定义层（9 个 Agent）

| # | 角色 | 职责 | 输出物 |
|---|---|---|---|
| 1 | **主理人（CIO）** | 拆解任务、主持投研会、分发任务、汇总观点、协调冲突、裁决最终方案 | 会议纪要 + 调仓结论 |
| 2 | **投研经理** | 资产归因、组合仓位测算、生成候选调仓清单 | 归因报告 + 候选清单 |
| 3 | **深度研究员** | 个股多维度估值、蒙特卡洛概率模拟、执行价格测算 | 估值区间 + 概率分布 |
| 4 | **风控官** | 舆情/事件驱动/合规/回撤压力风险扫描 | 风险清单 + 压力测试 |
| 5 | **交易员** | 交易可行性、流动性、分批下单、滑点预估 | 执行方案 |
| 6 | **行业分析师** | 行业景气度、产业链上下游、政策影响 | 行业判断 |
| 7 | **宏观分析师** | 利率/通胀/货币政策对大盘与板块影响 | 宏观研判 |
| 8 | **量化校验** | 校验量化指标、相关性矩阵、历史统计检验、模型偏差 | 校验报告 |
| 9 | **合规审查** | 核查结论与推荐表述，保证符合金融宣传合规 | 合规意见 |

### 3. 群智协作流程（4 轮）

| 轮次 | 名称 | 机制 | 关键点 |
|---|---|---|---|
| 第 0 轮 | **独立闭门输出** | 9 Agent 并行独立思考，互不可参考 | 基于标的 + Kronos 预测输出「观点/论据/风险点」 |
| 第 1 轮 | **圆桌辩论** | 全员公开观点，对立观点互相质疑 | 质疑假设、数据前提、逻辑漏洞 |
| 第 2 轮 | **交叉互评（幻觉排查）** | Agent 互评报告 | 识别逻辑断层/数据错误/主观幻觉/参数假设缺陷 |
| 第 3 轮 | **共识汇总与裁决** | 主理人整合→权衡分歧→裁决 | 输出结论 + 调仓方案，**标记尚存争议点** |

### 4. 专业能力层

- 批量标的分析：≤20 只，含**相关性矩阵**
- 个股估值：多维度估值模型 + **与 Kronos 预测交叉验证**
- 蒙特卡洛：**万次级**情景模拟（组合收益/回撤分布）
- 风险扫描：舆情 / 突发事件 / 合规 / 尾部风险
- 调仓清单：标的 + 方向 + 仓位比例 + 价格区间 + 止损止盈
- 内部工具对接：读取 Kronos 预测数据/置信度/预测区间，作为核心输入之一

### 5. 治理与质检

- **全流程审计留痕**：每轮发言/辩论/修改/原始输入/最终输出，全程可回溯
- **回测质检**：用历史行情回测调仓方案，评估策略历史表现
- **系统迭代机制**：日间处理任务；夜间基于历史+回测迭代 prompt/评估逻辑
- **角色可扩展架构**：新增行业/主题 Agent 不破坏工作流

### 6. 外部数据源连接器

| 类型 | 需求 | 现有能力 |
|---|---|---|
| 行情 API | 价格/成交量/财务指标 | ✅ 已有（腾讯行情 + 东财财务） |
| 舆情 API | 新闻/股吧/研报情感 | ⚠️ 部分（已有公司公告 + 每日要闻，缺情感分析） |
| 行业研报库 | 券商公开研报 | ❌ 新建（可用东财研报接口） |
| 风控规则库 | 阈值/合规规则/判定标准 | ❌ 新建（内置规则表） |
| 内部接口 | Kronos 预测数据/置信度/区间 | ✅ 已有（kronos_service） |

### 7. 输出物规范（3 部分）

1. **投研会议完整纪要**：各角色观点 + 辩论 + 互评完整记录
2. **标的综合分析报告**：现状 + 收益预期 + 风险清单 + 约束假设
3. **结构化调仓清单**（JSON，便于下游系统读取）

### 8. 约束规则（硬性）

1. ❌ 禁止"保本/稳赚"类承诺性表述
2. ✅ 所有结论标注**假设条件、不确定性、置信水平** + "不构成投资建议"
3. ✅ 重大分歧时主理人**必须显式列出分歧点**，不得掩盖
4. ✅ Kronos 预测与多 Agent 结论冲突时**自动标记 + 报告内高亮对比**

## 二、与现有平台的融合映射

### 复用（已有能力，直接作为 Agent 输入）

| 现有模块 | 提供给哪些 Agent |
|---|---|
| `kronos_service.py`（预测+置信带） | 全部 9 Agent（核心输入）+ 量化校验（偏差校验） |
| `market.py`（行情/多周期K线/量比） | 交易员、量化校验、投研经理 |
| `indicators.py` + `signals.py`（指标/信号） | 量化校验、深度研究员 |
| `fundamentals.py`（估值/财务/公告） | 深度研究员、行业分析师、风控官 |
| `buysell.py`（买卖点/止损止盈） | 交易员、投研经理（调仓价格区间来源） |
| `backtest.py`（回测引擎） | 治理层「回测质检」 |
| `global_market.py`（外围指数） | 宏观分析师 |
| `recommend.py`（荐股/要闻） | 投研经理（候选池）、风控官（舆情） |
| `account.py`（多账户持仓） | 投研经理（组合归因输入） |

| 新模块 | 职责 | 依赖 |

| `analytics.py` | 专业能力层：归因/相关性矩阵/多维估值/蒙特卡洛/风险扫描 | 现有模块 |

## 四、合规与免责（贯穿全流程）

- 全部 Agent 输出经 `compliance.py` 过滤（禁词表 + 假设/置信度强制标注）
- 最终报告固定包含：**假设条件 / 不确定性说明 / 置信水平 / 不构成投资建议**
- 分歧点与「Kronos 预测 vs Agent 结论」冲突，均在报告中高亮
